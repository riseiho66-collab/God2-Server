## Recovered fully loaded transition

prepare_native_46c830 requires the original MBD full3x3 requested-center gate
before clamping through explicit MDT dimensions. A private candidate copies the
current valid slots. For absolute displacement>1, all native+54 flags are
invalidated. For adjacent displacement, x rotations occur before y rotations.
Positive x maps each row(old0,old1,old2) to(old1,old2,old0 invalid); negative x
maps it to(old2 invalid,old0,old1). Positive/negative y do the same by columns.
Diagonals invalidate both edges in this order. Allocation labels0..8 are internal
cache labels used to preserve reuse, never native pointer addresses or handles.

The following row-major load pass reuses valid coordinates and obtains actual
MBD data for invalid coordinates. Stale valid coordinates are an internal error;
missing clamped chunks are absence. With all nine actual terrain chunks present,
the existing native compositor overwrites all3969 cells and then applies the
complete declared MDL mask/marker order. Empty prior is justified by full
overwrite, not by invented native zero initialization. Raw cell2 is retained.

Candidates carry a private same-cache identity and expected generation.
commit accepts only that same instance/current generation. This CAS is local
integration policy for the real world owner; it is not a recovered native cache
counter, DB position revision, scene revision or movement permission. Preparation
does not mutate active cache state, player storage, wire state or peers. The real
world transaction/publication must consume the candidate at the proper point.
