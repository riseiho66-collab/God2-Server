## 命名空間與證據層級

- Mission_data 第一欄 44～50 是 **journal 定義 ID**；其描述列第三欄 1..N 是顯示描述索引。N=5 不證明五個依序轉移狀態。
- NPCMission/NPCNormal 第一欄是各自**文字表 ID**。910、8779 等不是 quest ID，也不是 NPC 世界 instance ID。
- NPC 文中的「元始天尊／伙房師傅／仙童／拳頭師傅」是文字角色名稱。本輪沒有把它們綁到 world serial、map object、模板鍵或座標。
- gamedata 道具第一欄是 item lookup key；第三欄圖檔代稱及第四欄資源鍵不是 quest ID。名稱相同不等於同一物品。
- 下表「對話」均為語義相關候選；沒有恢復 journal ID→text ID 的權威 join。連號、檔案順序與「接下來」都不當成 server 狀態轉移。
