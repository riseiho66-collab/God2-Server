CUSTOM-0013 now has an opt-in isolated Application caller. The new
diagnostic_progress_span defaults0, preserving the prior independent sentinel.
Nonzero requires diagnostic_role_progress and existing persisted terminal award
gates. Config rejects negative, fractional, noninteger, oversized, and intervals
not larger than the configured fresh test award. Runner rejects restored DBs
for this bounded fresh-state experiment.

After the terminal resource/XP transaction and before battle release, Application
loads owned XP with CUSTOM-0012 provenance and passes total plus explicit table
{0,span} to LuaEngine::progression, unlock gate2. Projection must return level1;
an earned level transition is rejected rather than silently changing progress
without a corresponding native level packet. Role HP/MP also come from storage.
The Lua result replaces the diagnostic2B progress field. There is no C++ copy
of the gameplay fraction formula. No production table, growth or level mutation.
