## Actual hosting registry

Previously controller composition compared directory nodes with declared
plan.host/port. The source factory ran before bind/listen, so it could not
obtain a successfully bound socket registry through its temporary Context.

`SharedCredentialServer` now validates the explicit plan, constructs the same
verifier/admission/state, binds/listens on all actual endpoints, and obtains
their `acceptor.local_endpoint()` values BEFORE invoking the controller
factory. No async accept is started before every mandatory controller exists.
Factory/bind failure closes partially constructed listener members on the game
owner; no nominal registry is activated by a failed construction. This changes
the authorized CN source-host construction order, not ordinary main activation.

`SharedListenerRegistry` has a private constructor/start/stop available only to
the real server. Context receives a retained const registry, never a caller-
fabricated vector plus default-true predicate. Rows have actual role, optional
world target and bound socket. `bound_endpoints()` remains available before
start for the existing Application/web setup; Application itself is unchanged.

Publication snapshots exist only after managed start and before stop. Copies
retain the same immutable registry identity, so stop permanently invalidates
all copies; a new server gets a different owner. Snapshot creation/read/current
and invalidation stay on the constructing game thread; no network handler
mutates registry state. Stop invalidates the registry BEFORE posting socket
closure or closing account transports. No old port/PID/handle is reused.

The start flag is managed hosting lifetime. It is not a network health probe,
proof of reachability, confirmed socket delivery or native client acceptance.
The registry does not replace later failure/recovery tests or WSS/TLS policy.
