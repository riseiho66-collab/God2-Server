## Adoption Rules

For each production skill/stat/reward design, record the exact source page and
row, retrieval date, game/region/generation, and units. Distinguish source claims,
current-client corroboration, chosen custom deviations and unresolved gaps.
An indexed excerpt is a lead, not proof of a complete recovered table.

Prefer compatible documented values over arbitrary new numbers. Cross-check
names and IDs against current catalogs, not name similarity alone. Conflicting
versions remain separate. Pet attributes do not establish wild-monster stats.
Preserve field-level provenance when one record mixes sources/custom values.

Custom balance acceptance should compare same-level normal attacks and skills,
MP efficiency, turns-to-defeat, survivability, critical spikes and pet/player
roles. Test low/mid/high levels and equipment tiers with documented inputs.
Report resulting tuning as CUSTOM, not recovered original formula. Never infer
official drop rates or damage equations solely because a guide gives examples.

CUSTOM-0006's current tests establish arithmetic and bounds only, NOT game
balance. No existing custom formula or monster/skill parameter becomes balanced
or native merely because these sources have been registered. No formal database
values were changed by this source-index update.
