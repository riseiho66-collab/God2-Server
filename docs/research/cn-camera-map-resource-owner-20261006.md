Only printable ASCII identity is qualified here; unknown CP936/path variants
raise an explicit error. CnOutdoorSceneResources checks the complete.map suffix,
delimiter, two decoded axes and requested coordinates, reconstructs.mdt and
matches the actual retained identity with ASCII case folding. It never performs
slash/Unicode/locale normalization or picks an alternate filesystem resource.

identity/generation candidate with a switch request. After resource matching it
