## Source lifetime and failure behavior

- A prior pending cohort is joined before a new registry.begin invalidates it.
- selection_unjoined retires the old baseline before original C67 dispatch.
  An incomplete full predecessor may keep the independent original selection
  flow, but releases the learning Entry and cannot renew it from saved equality.
- Pending never queries its consumed predecessor. NoOutput or a failed full
  successor retires continuity; old learning publications cannot be replayed.
- A failed physical output closes the Session; committed SQL is not retried.
- A Written source must match the pending occurrence, never the registry's
  historical latest token in isolation.
- Reentry poisons preparation/dispatch and abandons the active private callback.
  Final publication rechecks the original holder, INIT, full identity and state.
- No shared whole-response receipt, common-world lease, PK observation, battle
  admission or native acknowledgement is minted for the legacy path.
- The source review removed an iterator retained across source observations:
