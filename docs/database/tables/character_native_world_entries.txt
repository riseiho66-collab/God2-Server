CUSTOM-0142 明確使用者前後排顯示選擇（獨立種類，不覆寫原 2A）：
record_kind = tw_b4_row_choice_e8_v1。
record 固定 2 bytes：第一個 byte 為 E8，第二個 byte 為使用者實際 B4 選擇。
第二個 byte：0 = 前排（原 UI control 18）；1 = 後排（原 UI control 19）。
只保存真實已驗證的 B4 選擇；沒有保存就不產生預設 0 或 1。
這是經使用者授權的 CUSTOM 顯示設定保存／重登入回放，並非已復原的原服保存規則。
不代表戰鬥人物／戰寵初始 slot、前後排戰鬥部署、技能權限或戰後重置規則。
